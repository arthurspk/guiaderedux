## :dart: O guia para alavancar a sua carreira

> Redux é a biblioteca de gerenciamento de estado mais usada do ecossistema JavaScript: um único "store" previsível, ações que descrevem o que aconteceu e reducers puros que decidem como o estado muda — tudo inspecionável com viagem no tempo pelo Redux DevTools. Hoje o jeito oficial de escrever Redux é com o **Redux Toolkit (RTK)**, que elimina o boilerplate clássico, e o **RTK Query**, que resolve busca e cache de dados de servidor sem bibliotecas extras. Este guia reúne documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas, projetos práticos e um capítulo dedicado a usar IA na prática com Redux — tudo verificado e organizado para quem já conhece React e quer dominar estado global de verdade, do primeiro `configureStore` a arquiteturas com `createSlice`, `createEntityAdapter` e `RTK Query`.

## 📖 Documentação oficial

- [Redux — documentação oficial](https://redux.js.org/) — Ponto de partida oficial: conceitos, tutoriais e referência da API mantidos pela equipe do Redux.
- [Getting Started with Redux (oficial)](https://redux.js.org/introduction/getting-started) — Instalação, primeiros passos e visão geral da biblioteca.
- [Redux Toolkit — documentação oficial](https://redux-toolkit.js.org/) — A forma oficial e recomendada de escrever Redux hoje, com `configureStore`, `createSlice` e `createAsyncThunk`.
- [Redux Toolkit — Quick Start (oficial)](https://redux-toolkit.js.org/tutorials/quick-start) — Configure uma store completa com Redux Toolkit em poucos minutos.
- [Redux Toolkit — usando com TypeScript (oficial)](https://redux-toolkit.js.org/usage/usage-with-typescript) — Guia oficial de tipagem: `RootState`, `AppDispatch` e hooks tipados.
- [createSlice — referência da API (oficial)](https://redux-toolkit.js.org/api/createSlice) — Documentação da função central do Redux Toolkit, que junta reducers e actions em um só lugar.
- [RTK Query — visão geral (oficial)](https://redux-toolkit.js.org/rtk-query/overview) — A solução oficial de busca e cache de dados de servidor integrada ao Redux Toolkit.
- [RTK Query — exemplos de uso (oficial)](https://redux-toolkit.js.org/rtk-query/usage/examples) — Casos práticos com paginação, autenticação, invalidação de cache e mutações.
- [Redux Toolkit — Migrating to Modern Redux (oficial)](https://redux-toolkit.js.org/usage/migrating-to-modern-redux) — Guia oficial para migrar Redux "clássico" (`connect`, reducers com `switch`) para Redux Toolkit.
- [React Redux — documentação oficial](https://react-redux.js.org/) — Bindings oficiais entre Redux e React: `Provider`, `useSelector`, `useDispatch`.
- [React Redux — Quick Start (oficial)](https://react-redux.js.org/tutorials/quick-start) — Conecte uma aplicação React a uma store Redux em minutos.
- [Redux — FAQ (oficial)](https://redux.js.org/faq) — Respostas oficiais para as dúvidas mais comuns sobre performance, estrutura de estado e boas práticas.
- [Redux — Glossário (oficial)](https://redux.js.org/understanding/thinking-in-redux/glossary) — Definições oficiais dos termos: action, reducer, store, dispatch, middleware.
- [Redux-Saga — documentação oficial](https://redux-saga.js.org/) — Middleware alternativo ao `createAsyncThunk` para efeitos colaterais complexos usando generators.
- [Immer — documentação oficial](https://immerjs.github.io/immer/) — A biblioteca que o Redux Toolkit usa por baixo dos panos para permitir "mutar" o estado de forma seguraimutável.
- [Redux Toolkit — notas de lançamento (GitHub Releases)](https://github.com/reduxjs/redux-toolkit/releases) — Changelog oficial de cada versão, incluindo a série 2.x com as novidades mais recentes.

## 🤖 IA na prática

Redux tem uma particularidade importante para quem usa IA: é uma biblioteca com **mais de dez anos de tutoriais na internet**, então assistentes de código frequentemente sugerem o Redux "clássico" (`connect`, `mapStateToProps`, reducers com `switch/case` e action types como string solta) quando o certo hoje é usar o **Redux Toolkit**. Use isso a seu favor, mas sempre com revisão.

**Para aprender**
- Peça para a IA **explicar um trecho de `createSlice` linha a linha**: o que é o `initialState`, como o Immer permite "mutar" o estado dentro do reducer, e o que o RTK gera automaticamente (action creators e action types).
- Cole um reducer clássico com `switch/case` e peça para **reescrevê-lo com `createSlice`**, depois compare as duas versões para entender o que mudou.
- Peça **exercícios com gabarito** sobre um tópico específico (selectors memoizados, `createAsyncThunk`, normalização de estado com `createEntityAdapter`).
- Peça para explicar a diferença entre `useSelector`/`useDispatch` e os hooks tipados (`useAppSelector`/`useAppDispatch`) recomendados pela documentação oficial de TypeScript.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para: gerar `slices` completos com `createSlice`, converter chamadas manuais de `fetch`/`axios` para endpoints de **RTK Query**, e escrever `selectors` memoizados com Reselect.
- Peça para **migrar um componente com `connect()` (Redux "clássico") para hooks** (`useSelector`/`useDispatch`) — é uma tarefa mecânica e repetitiva em que a IA costuma acertar bem, mas confira se o componente ainda re-renderiza corretamente.
- Depois de aceitar uma sugestão, **abra o Redux DevTools** e confirme que as actions disparadas e o novo estado são exatamente os esperados — é a forma mais rápida de pegar um erro de reducer gerado por IA.

**Limites e boas práticas**
- IA **mistura a API antiga com a nova**: pode sugerir `applyMiddleware` manual, `combineReducers` isolado ou `redux-thunk` importado à parte — hoje isso já vem embutido no `configureStore`. Sempre confira contra a [documentação oficial](https://redux-toolkit.js.org/).
- Cuidado com **mutação de estado fora do Immer**: peça sempre para o código ficar dentro de um `createSlice`/`createReducer`; fora deles, "mutar" o estado quebra o Redux.
- Não cole tokens de autenticação, chaves de API ou dados de clientes reais ao montar exemplos de `RTK Query` com uma ferramenta de IA.
- Entenda o fluxo de dados gerado: em entrevista técnica e em produção, você precisa explicar por que cada action e cada reducer existem.
